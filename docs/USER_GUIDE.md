# User guide

Open <http://localhost/pms/> (or the address your administrator gives you). Every page has the navigation on the left (menu button on phones), your name, role and station at the bottom of it, and **Profile** / **Logout** buttons. You are signed out automatically after 30 minutes without activity.

## Everyone

- **Sign in** with your username and password. Head office and station admins have their own login pages, but any account works from any of the three.
- **Forgot password**: enter your username or email; if the account has an email address you receive a link valid for 30 minutes (usable once). Without email, ask an administrator to set a new password.
- **Profile**: update your contact email; change your password (current password required; other devices are signed out).
- **Alerts** on your dashboard show notices for everyone, your district or your station, only while they are live.

## Staff

| Task | Where | Notes |
|---|---|---|
| File a crime report | New Report | Reference number (PMS-year-number) is assigned on save; you can then attach evidence files (images, PDF, Word, text, MP3, MP4; 5 MB each). |
| See station reports | Station Reports | Read-only list of your station's reports with filters; open a report to see details, history and evidence. Accused CNICs are masked. |
| Edit my report | open the report → *Edit details* | Only your own report and only while it is *Open*. |
| See my duties | My Duties | List (upcoming / past) or calendar; overnight duties span two days. |
| Request leave | Request Leave | Choose type and dates; the page shows your remaining days per type for the year. Overlapping or over-allowance requests are refused. |
| Track / withdraw leave | My Leave | Pending requests can be withdrawn until their start date. |

## Station admin (station in-charge)

Everything a staff member can do, plus, for your own station only:

| Task | Where | Notes |
|---|---|---|
| Station overview | Station Dashboard | Counts, charts, upcoming duties, pending leave, failed emails to retry. |
| Manage reports | Reports | Filter, sort, export CSV; open a report to change status (Open → Under Investigation → Closed, reopen), assign an officer, add or remove evidence, archive with a reason. |
| Search by CNIC | Search Criminal | All reports against an accused CNIC in your station. |
| Manage staff | Staff → Add staff / Edit / Deactivate | You can create *staff* and *station admin* accounts, reset their passwords, and deactivate them. You cannot create head office admins or move staff to another station. |
| Assign duties | Assign Duty / Duties | The system warns about overlapping duties and approved leave; tick *Save anyway* to override. The staff member is emailed if email is configured; failed emails can be retried from the duty page. Mark duties completed or cancel them with a reason. |
| Review leave | Leave Requests | Approve (optionally fewer days) or reject with a reason. Balances are enforced per type per year. |
| Station alerts | Alerts | Alerts you create go to your station only; set an optional start and expiry. |

## Head office admin

Everything above across all stations, plus:

| Task | Where |
|---|---|
| Add, edit, rename, deactivate stations (delete only when empty) | Police Stations |
| Create accounts of any role, including other head office admins; deactivate/reactivate anyone except yourself | Staff |
| Restore archived reports | open the report → *Restore* |
| Report analysis with charts and CSV export across stations | Report Analysis |
| Alerts to everyone, a district or a station | Alerts |
| Configure leave types and yearly allowances | Leave Requests → *Leave types* |
| Audit log of logins and changes | Audit Log |

## Printing a report

Open the report → **Print view** → use the browser's *Print* or *Save as PDF*. This is a plain print layout; it does not reproduce any official FIR form.
